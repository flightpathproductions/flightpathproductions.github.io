# flightpathproductions.github.io
Flight Path Films static site

# Getting started

## Installation

To prepare the site for viewing locally, first install local packages by running in the terminal

```
npm install
```

then to run the repository locally, run 

```
npm start
```

## Build for Production

To build the project for production you simply need to make sure you've installed the packages locally, and then run 

```
npm run build
```

This will create the `dist` folder.
